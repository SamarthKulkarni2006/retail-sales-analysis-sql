

\# Data Dictionary — Retail Sales Analysis



| Column | Description | Data Type |

|---|---|---|

| Ship Mode | Shipping method used to deliver the order | Text |

| Segment | Customer segment, such as Consumer or Corporate | Text |

| Country | Country where the order was placed | Text |

| City | City associated with the order | Text |

| State | State associated with the order | Text |

| Postal Code | Postal code associated with the order | Integer/Text |

| Region | Sales region, such as East, West, Central, or South | Text |

| Category | Main product category | Text |

| Sub-Category | Specific product type within a category | Text |

| Sales | Revenue generated by the sale | Decimal |

| Quantity | Number of items sold | Integer |

| Discount | Discount applied to the sale | Decimal |

| Profit | Profit or loss generated by the sale | Decimal |



\## Dataset Notes



\- Dataset: Sample Superstore

\- Source: Kaggle

\- Records: Approximately 9,994

\- Columns: 13

\- Negative profit values represent losses.

\- Discount values are stored as decimals. For example, `0.2` represents a 20% discount.
